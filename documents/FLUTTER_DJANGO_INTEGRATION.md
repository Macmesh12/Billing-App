# Flutter-Django Integration Summary

## Architecture Overview

**Frontend:** Pure Flutter (Dart) - No HTML/WebView
**Backend:** Django REST APIs
**PDF Generation:** Django (WeasyPrint)

## What Was Changed

### 1. Removed HTML/WebView Components
- ❌ Deleted `webview_flutter` dependency
- ❌ Removed `flutter /assets/` directory (HTML preview files and CSS)
- ❌ Removed `flutter /utils/pdf_generator.dart` (Flutter PDF generation)
- ❌ Removed `printing` and `pdf` packages

### 2. Added Django API Integration
- ✅ Created `flutter /services/api_service.dart` - API client for Django backend
- ✅ Added `http` package for API calls
- ✅ Added `path_provider` for file storage

### 3. Updated Flutter Screens
- ✅ InvoiceScreen now uses pure Flutter widgets (no WebView)
- ✅ Preview mode shows Flutter-rendered invoice preview
- ✅ PDF export calls Django API endpoint
- ✅ Invoices are saved to Django backend before PDF generation

## API Endpoints Used

### Invoices
- `POST /invoices/api/create/` - Create invoice
- `GET /invoices/api/<id>/` - Get invoice details
- `GET /invoices/<id>/pdf/` - Download PDF (generated by Django)

### Receipts
- `POST /receipts/api/create/` - Create receipt
- `GET /receipts/api/<id>/` - Get receipt details
- `GET /receipts/<id>/pdf/` - Download PDF

### Waybills
- `POST /waybills/api/create/` - Create waybill
- `GET /waybills/api/<id>/` - Get waybill details
- `GET /waybills/<id>/pdf/` - Download PDF

## How It Works

### Creating and Exporting Invoice

1. **User creates invoice in Flutter**
   - Fills form fields in InvoiceScreen
   - Clicks "Preview" to see Flutter-rendered preview

2. **User exports PDF**
   - Clicks "Export PDF" button
   - Flutter calls `ApiService.createInvoice()` → sends data to Django
   - Django saves invoice and returns ID
   - Flutter calls `ApiService.downloadInvoicePDF(id)` → Django generates PDF with WeasyPrint
   - Flutter saves PDF to device using `path_provider`

### Backend Configuration

Update `ApiService.baseUrl` in `flutter /services/api_service.dart`:

```dart
static const String baseUrl = 'http://localhost:8765';  // Development
// or
static const String baseUrl = 'https://your-backend.com';  // Production
```
